# The Glass Calculator

The Glass Calculator is a modern, visually appealing calculator application designed with a sleek glassmorphism UI.

## Live Demo

Try it out here: [The Glass Calculator Live](https://q9kawaii.github.io/The-Glass-Calculator/)

## Features

- **Glassmorphism UI**: Elegant, frosted glass-like design.
- **Basic Arithmetic Operations**: Supports addition, subtraction, multiplication, and division.
- **Responsive Design**: Works seamlessly on different screen sizes.
- **Lightweight**: Optimized for smooth performance.

## Technologies Used

- **HTML**: Structure of the calculator.
- **CSS**: Styling with a glassmorphism effect.
- **JavaScript**: Handles calculations and interactions.

## Installation

To use The Glass Calculator locally:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Q9Kawaii/The-Glass-Calculator.git
   ```
2. **Navigate to the Project Directory**:
   ```bash
   cd The-Glass-Calculator
   ```
3. **Open `index.html` in a Browser**:
   - Open the `index.html` file in any modern web browser.
